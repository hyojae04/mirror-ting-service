## 공통 헤더 및 한 화면 레이아웃

- 실제 설문은 홈과 같은 `TopNav`·모바일 메뉴를 재사용한다. 별도 설문 헤더와 예전 작업 공간용 좌측 여백은 제거했다. 비교용 iframe 미리보기는 기존 독립 프레임을 유지한다.
- 공통 헤더의 높이(80px)·배경·메뉴 스타일을 맞췄다. 작성 중 공통 메뉴나 로고로 이동하면 답변이 사라지는지 확인하며, 취소하면 입력을 유지한다. 로그인·회원가입 준비 중 배너는 기존 동작을 유지한다.
- 연습 방식은 PC에서 두 열, 최종 확인은 세 열로 구성하고 여백·카드 높이를 조정했다. 아이콘을 먼저 보는 선택 카드, 필수 항목·추가 사항·전송 동의는 유지한다. 폰트는 본문 14px, 입력 16px 이상을 유지한다.
- `node qa/survey/layout.mjs`: 1440×900·1366×768·1280×720·1024×768에서 기본 설문 네 단계(16개 상태)가 페이지 스크롤 없이 들어옴을 확인했다. 390×844·320×568에서는 가로 넘침 없이 선택·이동할 수 있다. 모바일의 긴 단계와 긴 답변·확장한 추가 사항은 내용 삭제나 가림 대신 자연 스크롤을 허용한다. 모든 입력 길이와 모든 창 크기에서 무조건 한 화면이라고 보장하지 않는다.
- 헤더 스타일 일치, 작성 중 이동 취소 시 답변 보존, 이동 확인 후 페이지 전환과 새 설문 초기화를 검증했다. 기존 설문 6개 너비×5개 상태와 사용 방법 6개 너비×3개 상태의 흐름·접근성 검사도 통과했다. 타입 검사와 서버 테스트 3개가 통과했다. 이번 검증은 캡처를 저장하지 않았다.

## 상황 선택 드롭다운

‘연습하고 싶은 상황’은 기본 `<select>`로 선택한다. 면접·직장 대화의 기존 선택값과 ‘직접 정할게요’를 유지하며, 직접 선택 시 별도 입력칸이 나타난다. 필수값이 비어 있으면 드롭다운에, 직접 입력이 비었으면 해당 입력칸에 오류 포커스가 간다. 기존 입력·목표·상대·동의와 API 데이터 형식은 유지한다.

검증: 여섯 너비의 전체 설문 흐름·접근성, 공통 헤더와 선택 보존 회귀 검사가 통과했다. 1440·390·320px에서 직접 입력 유지, 기본 선택 복원, 모드 전환 시 옵션·값 초기화, 키보드 포커스와 제출 전 AI 호출 0회를 별도 확인했다. 캡처 이미지는 저장하지 않았다. 사용자 요청에 따라 한 화면 표시를 강제하지 않고 긴 내용은 자연 스크롤을 허용한다.
